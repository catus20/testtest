# Sauna-bakgrunnsbilete

Legg dei tre bileta frå prompten i denne mappa med namna:

- `sauna-floating.jpg` – flytande badstu på fjorden (brukast i heroen).
- `sauna-interior-timber.jpg` – tømra badstueinteriør (brukast i «Kven er me?»).
- `sauna-steam.jpg` – badstuebenkar med damp (brukast i «Det som skjer»).

Filnamna må stemme for at bakgrunnane skal visast korrekt.
